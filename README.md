## ⚡ Key Features
<a id="key-features"></a>

### Core Functionality:
- **Audio and MIDI Recording** — Seamlessly capture audio and MIDI with high precision.
- **Virtual Instruments and Effects** — Utilize a wide range of VST/VSTi plugins for creative sound design.
- **Intuitive Interface** — Easily manage your projects with a user-friendly design that supports drag-and-drop functionality.
- **Automation** — Effortlessly apply automation to any track by simply drawing the process.
- **Real-time Effect Processing** — Experience instant feedback and adjustments with real-time audio processing.

### Advanced Features:
- **ReWire Support** — Connect with other DAWs like Reason, ProTools, and Ableton Live for enhanced workflow.
- **ASIO and MME Compatibility** — Ensure low-latency audio performance with support for various sound cards.
- **Sidechain Options** — Easily create dynamic mixes with sidechaining capabilities.
- **Built-in Effects and Instruments** — Start producing immediately with an extensive collection of effects and instruments.
